## 1. ログイン方法

1. ブラウザで上記URLにアクセスすると、ログイン画面が表示されます。
2. 管理者から発行された **社員ID** と **パスワード** を入力します。
3. 「ログイン」ボタンを押します。

- 社員IDまたはパスワードが誤っている場合は、画面にエラーメッセージが表示されます。再度入力し直してください。
- ログインすると、画面上部に自分の氏名と社員IDが表示されます。管理者権限を持つアカウントの場合は、上部メニューに「管理者メニュー」が追加で表示されます。
- ログイン情報（社員ID・パスワード）が分からない場合は、管理者に確認してください。

## 2. 社員向け機能

ログイン後、画面上部のメニューから以下の3つのページに移動できます。

| メニュー | 内容 |
|---|---|
| 打刻 | 出勤・退勤・休憩の打刻（ログイン後のトップページ） |
| 勤怠履歴 | 自分の月ごとの打刻記録の確認 |
| 修正申請 | 打刻ミスがあった場合の修正申請と、申請状況の確認 |

### 2.1 打刻（出勤・退勤・休憩）

トップページ（「打刻」）では、その日の出勤・退勤・休憩開始・休憩終了の時刻と、状況に応じたボタンが表示されます。

操作の流れ：

1. 出社したら **「出勤」** ボタンを押します。
2. 休憩に入るときは **「休憩開始」** ボタンを押します。
3. 休憩から戻ったら **「休憩終了」** ボタンを押します。
4. 退社するときは **「退勤」** ボタンを押します。

補足：

- ボタンはその日の打刻状況に応じて自動的に切り替わります（例：出勤前は「出勤」のみ表示、出勤後は「休憩開始」と「退勤」が表示）。
- 休憩は1日1回のみ記録できます（休憩終了後は「休憩開始」ボタンは表示されません）。
- 退勤を押すと「本日の勤務は終了しました。お疲れさまでした。」と表示され、その日はこれ以上打刻できません。
- 打刻を押し間違えた場合は、そのまま担当者・管理者に相談するか、[2.3 打刻修正申請](#23-打刻修正申請)から修正を申請してください。

### 2.2 勤怠履歴の確認

「勤怠履歴」メニューでは、自分の月ごとの打刻記録を一覧で確認できます。

- 「← 前月」「翌月 →」のリンクで表示する月を切り替えられます。
- 各行には、日付・出勤時刻・退勤時刻・休憩時間・状態（通常／修正済み／未打刻）が表示されます。
- 打刻がない日は「未打刻」と表示されます。

### 2.3 打刻修正申請

打刻を忘れた、または間違えた場合は、修正申請を行うことで管理者に修正を依頼できます。

**申請手順：**

1. 「修正申請」メニューを開きます（過去の申請一覧が表示されます）。
2. 右上の **「新規申請」** ボタンを押します。
3. 以下の項目を入力します。
   - **対象日**（必須）：修正したい日付
   - **出勤時刻／退勤時刻／休憩開始／休憩終了**（任意）：正しい時刻。変更が不要な項目は空欄のままで構いません。
   - **理由**（必須）：修正が必要な理由（500文字以内）
4. **「申請する」** ボタンを押して送信します。

**申請状況の確認：**

- 「修正申請」メニューの一覧で、申請ごとに以下のステータスが表示されます。
  - **承認待ち**：管理者の確認待ちです。
  - **承認済み**：管理者が承認し、打刻記録が修正されました。
  - **却下**：申請が却下されました。管理者からコメントが付いている場合は、その内容が表示されます。

## 3. 管理者向け機能

管理者アカウントでログインすると、上部メニューに **「管理者メニュー」** が表示されます。これを開くと、管理者専用の3つの機能に移動できます。

| メニュー | 内容 |
|---|---|
| 社員管理 | 社員アカウントの新規登録・編集 |
| 修正申請承認 | 社員からの打刻修正申請の承認・却下 |
| 勤怠一覧・CSV | 全社員の月次勤怠の確認とCSVダウンロード |

### 3.1 社員管理

「社員管理」画面では、登録されている全社員（管理者含む）の一覧が確認できます。表示項目は社員ID・氏名・権限（社員／管理者）・状態（有効／無効）です。

**新規社員の登録：**

1. 「新規登録」ボタンを押します。
2. 以下を入力します。
   - **社員ID**：半角英数字・ハイフン・アンダースコアのみ（他の社員IDと重複不可）
   - **氏名**
   - **初期パスワード**：4文字以上
   - **権限**：「社員」または「管理者」
3. 「登録する」ボタンを押すと登録が完了し、一覧に反映されます。
4. 発行した社員IDと初期パスワードは、本人に安全な方法で伝達してください。

**既存社員の編集：**

1. 一覧の対象行にある「編集」リンクを押します。
2. 以下を変更できます。
   - **氏名**
   - **権限**（社員／管理者への変更）
   - **状態**（有効／無効。退職者などは「無効」に設定することでログインを禁止できます）
   - **パスワード再設定**（任意。入力した場合のみ変更されます。空欄なら現在のパスワードのまま）
3. 「更新する」ボタンで保存します。

> 社員IDそのものは登録後に変更できません。

### 3.2 打刻修正申請の承認

「修正申請承認」画面には、**承認待ち**の申請のみが一覧表示されます（申請日時の古い順）。各申請には申請者名・対象日・修正希望時刻・理由が表示されます。

- **承認する場合**：必要であればコメント欄に一言添えて「承認」ボタンを押します。承認すると、対象社員の打刻記録が申請内容に更新されます。
- **却下する場合**：必要であれば却下理由をコメント欄に入力し「却下」ボタンを押します。

承認・却下いずれの場合も、結果は申請者本人の「修正申請」画面に反映され、コメントも表示されます。

### 3.3 月次勤怠一覧・CSV出力

「勤怠一覧・CSV」画面では、全社員の月ごとの打刻記録を確認できます。

- **社員で絞り込み**：プルダウンから対象の社員を選択（「全社員」で全員分を表示）。
- **対象月を指定**：月選択欄で確認したい年月を選び、「絞り込み」ボタンを押します。
- **CSVダウンロード**：右上の「CSVダウンロード」ボタンを押すと、現在の絞り込み条件（社員・月）に応じたCSVファイルをダウンロードできます。給与計算や勤怠集計に利用してください。

一覧の各行には、社員名・社員ID・日付・出勤／退勤時刻・休憩時間・状態（通常／修正済み／未打刻）が表示されます。

## 4. ログアウト

画面右上の **「ログアウト」** ボタンを押すと、ログイン画面に戻ります。共有端末を利用している場合は、離席前に必ずログアウトしてください。

## 5. よくある質問（FAQ）

**Q. 出勤ボタンを押し忘れて退勤を押してしまいました。**
A. 「修正申請」から対象日を選び、正しい出勤時刻を入力して申請してください。管理者の承認後、記録が修正されます。

**Q. パスワードを忘れました。**
A. 自分でパスワードを再設定する機能はありません。管理者に依頼し、「社員管理」の編集画面からパスワードを再設定してもらってください。

**Q. 「権限」の社員・管理者の違いは何ですか？**
A. 「社員」は打刻・履歴確認・修正申請のみ利用できます。「管理者」はそれに加えて、社員管理・修正申請の承認・全社員の勤怠一覧やCSV出力が行えます。

**Q. 退職した社員のアカウントはどうすればよいですか？**
A. 削除はせず、「社員管理」の編集画面で状態を「無効」に変更してください。ログインができなくなりますが、過去の勤怠記録は保持されます。

**Q. ログインできません。**
A. 社員IDとパスワードが正しいか確認してください。それでも解決しない場合は、アカウントが「無効」になっている可能性があるため、管理者に確認を依頼してください。
